# tinbox

局域网内的手机 ↔ 电脑文件互传：电脑开应用，手机扫码即连。不注册账号，不经过外网，文件只落在电脑本地。

- 扫码配对，令牌每次启动更换
- 双向传文件，图片 / 视频可直接预览
- 单层收件箱，没有文件夹树和版本历史
- Windows 电脑 + 手机浏览器（手机不要需装额外应用）

## 连接条件

手机和电脑必须在**同一个路由器**下面：

**电脑连 Wi-Fi**：手机连**同一个 Wi-Fi**（Wi-Fi 名称相同）。

或者

**电脑插网线**：手机连**这个路由器发出的 Wi-Fi**。

## 使用

1. 电脑端点「连接手机」，弹出二维码。
2. 手机扫码打开，自动配对并保持连接。
3. 在时间线里发送 / 接收文件；收到的文件落在收件箱。
4. 点右上角关闭默认隐藏到托盘（可在设置里改为直接退出）。

## 文件与日志

- 收件箱默认在 `%LOCALAPPDATA%\tinbox\inbox`，可在设置里更改（改后重启生效）。
- 日志在 `%LOCALAPPDATA%\tinbox\inbox.log`

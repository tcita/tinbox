# tinbox

局域网内的手机 ↔ 电脑文件互传：电脑开应用，手机扫码即连。不注册账号，不经过外网，文件只落在电脑本地。

- 扫码配对，令牌每次启动更换
- 双向传文件，图片 / 视频可直接预览
- 单层收件箱，无文件夹树，无版本历史
- Windows 电脑 + 手机浏览器（手机无需装应用）

## 连接条件

手机和电脑必须在**同一个路由器**下面，二选一：

1. **电脑连 Wi-Fi**：手机连**同一个 Wi-Fi**（Wi-Fi 名称相同）。
2. **电脑插网线**：手机连**这个路由器发出的 Wi-Fi**。

连不上时依次检查：Wi-Fi 名称是否一致（别连成访客网络）、手机是否关掉了移动数据和 VPN、电脑的 Wi-Fi 是否已连接 / 网线是否插好。

## 使用

1. 电脑端点「连接手机」，弹出二维码。
2. 手机扫码，自动配对并保持连接。
3. 在时间线里发送 / 接收文件；收到的文件落在收件箱。
4. 点右上角关闭只会隐藏到托盘（传输不中断），退出请走托盘菜单。

## 文件与日志

- 收件箱默认在 `%LOCALAPPDATA%\tinbox\inbox`，可在设置里改（改后重启生效）。
- 日志在 `%LOCALAPPDATA%\tinbox\inbox.log`，连不上时先看它：每一次手机请求、选中的配对 IP、多网段告警都在里面。

## 开发

```powershell
cd src-tauri
cargo run        # 调试运行
cargo test       # 单元测试
cargo build --release  # 发版构建（已做体积优化）
```

首次运行 Windows 防火墙会弹窗请求放行，允许即可；若之前点错了，应用内的修复指引会带你重来（`scripts/` 下另有手动清理脚本）。

前端无构建步骤：页面是单个 `src-tauri/src/index.html`，由服务端直接内嵌下发（`frontend/` 只是占位目录）。

# tinbox

局域网内的手机 ↔ 电脑文件互传：电脑开应用，手机扫码在浏览器打开后进行局域网传输。

- 扫码配对，令牌每次启动更换
- 双向传文件，图片 / 视频可直接预览
- 单层收件箱，没有文件夹树和版本历史
- Windows 电脑 + 手机浏览器

## 连接条件

手机和电脑必须在**同一个路由器**下面：

**电脑连 Wi-Fi**：手机连**同一个 Wi-Fi**（Wi-Fi 名称相同）。

或者

**电脑插网线**：手机连**这个路由器发出的 Wi-Fi**。

## 使用

1. 电脑端点「连接手机」，弹出二维码。
2. 手机扫码打开，自动配对并保持连接。
3. 在时间线里发送 / 接收文件；收到的文件落在收件箱。
4. 点右上角关闭默认隐藏到托盘。

## 首次运行：防火墙

tinbox 要在局域网建立起端口，第一次打开会经过两层系统确认：

1. **Windows 安全中心弹窗**： Windows 对任何监听端口的程序都会弹出此窗口。
2. **tinbox 自己的「允许局域网连接」弹窗**：点「允许」后会再弹出一个独立的**“用户帐户控制”（UAC）**窗口，请在其中**再次确认**。确认后规则生效，提示“防火墙已放行，可以连接了”。

这两个系统确认允许后一般不会再次出现。

## 文件与日志

- 收件箱默认位置 `%LOCALAPPDATA%\tinbox\inbox`，可以在设置里更改（重启生效）。
- 切换收件箱不会搬迁旧文件；重启后旧文件仍留在原处，但不再显示在时间线或由 tinbox 管理，文字历史保留。
- 日志位置 `%LOCALAPPDATA%\tinbox\inbox.log`
